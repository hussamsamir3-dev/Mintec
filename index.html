Load an updated workbook

Drop in the Mintec extract (the same Book1 layout — one tab per material, dates in column C, prices in column D). Everything on this page recalculates from it. The file never leaves your browser.

Drop the .xlsx here, or
Adding a new material is just a new tab in the workbook. The dashboard reads the category, currency and unit from each tab’s header block, so a new input appears with the right grouping automatically.

How this page stays current

Prices are baked into this file. Something has to rewrite it — a browser can’t call Mintec directly, and shouldn’t: it would put your client secret into a public web page.

Right now: —

Unattended, hourly

The GitHub Actions workflow calls Mintec every hour, rebuilds this file and commits it. Nothing needs to stay switched on. Credentials live in repository secrets.

From a machine you control

Run mintec_refresh.py --from-api --every 60 next to this file. Same result, inside your own network.

Right now, by hand

Refresh the workbook in Excel, then use Load workbook in the toolbar. Nothing leaves this browser and the page updates instantly.

Mintec authenticates with OAuth 2.0 — a client id and secret exchanged for a one-hour bearer token — against public-api.mintecanalytics.com/v2/export. The script implements that. A browser cannot, because Mintec sends no CORS headers.
